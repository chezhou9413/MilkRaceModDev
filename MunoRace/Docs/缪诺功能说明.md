# 缪诺功能说明

- **三种剧情开局**：缪诺开拓队由三名缪诺携带充足物资出发，与聚落保持同盟；生存挑战由一名缪诺和四名男性人类组成，通过拍摄兑换补给；缪诺叛逃者由一名缪诺和一名人类同伴组成，面对聚落追击。

- **聚落联络**：剧情开局可直接通过殖民者按钮联系聚落，办理聚落事务、上交录像带或申请融入结局，无需建造通讯台。

- **摄像机与录像兑换**：穿戴后自动定期拍摄附近殖民者，积累片段生成录像带。镜头朝向人物前方，配有举机动作、录制提示和快门音效。摄像机仅提供上传录像带按钮，可批量兑换食品、药品、钢铁、零部件或白银。

- **叛逃追击**：宽限期结束后，聚落定期派出追击队，强度随波次提升。达成和平、原始逃亡者全部离队或达成融入结局后，追击结束。

- **融入结局**：保留缪诺成员，将符合条件的非缪诺成员交给聚落，可分批通过穿梭机接送。根据最后一批实际交付时间，触发“开局跑路结局”或“跑路结局”，结局后可继续游戏。

- **穿梭机交付**：人员实际随穿梭机离场后，才结算交换奖励或结局进度，避免登机或起飞动画阶段提前结算。

- **自动汲取**：改善达到阈值后汲取不及时的问题，支持设置单次产量。乳源质条右上角显示产物图标和数量，点击循环切换；缪诺乳支持 5、25、50、100 份，浓浆支持 1、2、5 份，两种设置独立保存。
