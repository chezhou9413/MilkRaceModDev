# 缪诺军事支线

## 自然触发

两种支线进入原版随机任务池，选择权重各为 1。同类任务最多存在一条未接受邀请或进行中的任务，完成或失败后可再次随机出现。

任务要求启用皇权、存在地面玩家基地、缪诺派系存在且不敌对玩家，以及存在同时敌对玩家和缪诺、支持营地守军和袭击的人类派系。头衔检查涵盖地图、远行队及旅行运输器中的自由殖民者。

- **哨站活捉**：至少一名自由殖民者拥有“初级协助者”或更高缪诺头衔。接受后生成哨站和唯一指定目标，15 天内将其作为囚犯带回任意地面基地。返回后等待 1–2 天，穿梭机接收目标。目标必须活着装载并起飞，普通囚犯不能替代。
- **保护突袭队员**：至少拥有“高级协助者”头衔。接受后投放成年伤员，作为原版临时客人供玩家控制、救治。射击与格斗分别为 14–18 级；1–2 天后出现一波追兵。本次追兵全部死亡、倒地、被俘或撤离，且伤员存活并留在任务基地时，进入领奖。

邀请有效期均为 5 天，接收穿梭机停留 3 天。目标死亡、身份失效、离开交接基地、基地丢失、穿梭机损毁或接收超时会在任务日志中说明失败原因。

## 奖励

目标完成后发送可稍后处理的奖励选择信件，显示成员身份、技能、健康、特性、装备和具体物资。关闭窗口不会默认选择奖励。

- 抓捕任务：选择一名新缪诺成员或约 2,000 银币价值的物资。
- 保护任务：选择让受保护队员正式加入，保留当前技能、伤势和装备；或选择物资，先将队员送上接收穿梭机，起飞后再发奖。

候选奖励只生成一次，存档保存人物、物资、阶段、时限和领奖状态。任务穿梭机独立于通讯台人口交换会话。

## Debug 入口

启用开发者模式，在开发者动作菜单中搜索分类 **缪诺任务**：

1. **发出哨站抓捕邀请**：跳过头衔和自然随机选择，发出待接受的正式任务邀请。
2. **发出伤员保护邀请**：同样只发邀请，不自动接受、不授予头衔。
3. **立即派出抓捕接收穿梭机**：目标必须已经作为囚犯带回基地，且任务进入等待接收阶段。该操作仅提前执行正式穿梭机流程。
4. **立即生成保护任务追兵**：保护任务已经接受、伤员仍在基地，且本次追兵尚未生成时可用。

阶段不符时提示具体原因。Debug 保留地图和派系有效性检查、同类任务限制，不改变全局时间、不清除敌人，也不直接发奖。

## 配置和编译

`1.6/Defs/QuestScriptDefs/Muno_MilitaryQuests.xml` 保存任务权重、邀请有效期及 `MunoQuestConfig`：抓捕期限、接收延迟、穿梭机停留期限、物资预算、威胁倍率、队员技能范围和伤势范围。哨站威胁倍率默认 0.7，追兵默认 1，基础点数取当前殖民地原版威胁点数。

`Muno_MilitarySupport.xml` 定义指定目标部件、奖励选择信件与继承守卫装备的专用突袭队员类型。源码位于 `Source/MunoRaceLib/MunoQuests`，按通用流程、哨站抓捕、保护、奖励和调试划分目录。

编译命令：

```powershell
& 'E:\VS\MSBuild\Current\Bin\MSBuild.exe' 'E:\RimModDev\MunoRace\MunoRace\MunoRace\Source\MunoRaceLib\MunoRaceLib.csproj' /p:Configuration=Debug /p:Platform=AnyCPU /verbosity:minimal /nologo
```

输出到模组的 `1.6/Assemblies/MunoRaceLib.dll`。开发验证仅检查源码、XML 和编译，不启动游戏；运行时任务流程由玩家使用上述 Debug 入口检查。
