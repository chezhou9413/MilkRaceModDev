# 激光炮辐射爆发

## 参考与方向

- [Warframe：Qorvex / Crucible Blast](https://www.warframe.com/en/game/warframes/qorvex)：参考官方技能演示中集中发射、定向传导与命中爆发的分工。
- [Destiny 2：Chaos Reach](https://www.destinypedia.com/Chaos_Reach)：参考游戏画面中窄白核心、柔光外层、错相能量细丝与短火花的亮度层次。

只借鉴结构与节奏，未复制游戏素材。保留淡黄白核心与低饱和绿色余辉，适配 RimWorld 的俯视比例。

## 1.7 实现

发射时一次性采样 17 条射线的墙面和地图边界，组成弧形压力前沿；其中 7 条组成主次分明的束带。中心束最亮，侧束更细、更弱，各自拥有不同的起止时间。主体约半秒收束，火花与命中余波随后消散；承载 Mote 的总寿命为 1.1 秒。

命中反馈取实际伤害目标，最多同时绘制 16 个目标的闪点。墙面反馈取束带的截断位置。伤害、射程、夹角、友军误伤和浓浆消耗不变。不会生成持续覆盖锥形区域的烟雾。

束带、闪点、断环、火花和压力前沿共用一个网格和加色材质，每帧只有一次绘制和一次时间参数更新。网格在发射时生成，消失或卸载地图时释放；独立随机源只影响外观。辉光使用模组已有的专用层。

## 维护入口

- `Tools/Shaders/MunoTriangleRadiation.shader`：五类面片的视觉算法，保留资源名称以复用 CL 注册链。
- `1.7/Source/MunoRaceLib/MunoComp/Radiation/`：网格构建、墙面截断和播放生命周期。
- `1.7/Defs/ShaderDefs/MunoRace_TriangleRadiation.xml`：核心颜色、余辉颜色与发光强度。
- `Tools/Build/Build-RadiationShader.ps1`：离线编译标准资源并写入加色混合状态。
- `Tools/BuildMod.ps1`：同步共用内容、编译特效和程序集。
